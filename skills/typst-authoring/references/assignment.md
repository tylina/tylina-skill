# Assignment, Worksheet, and Exam Workflow

Read this only for `assignment` mode or when choosing an educational template.

## 1. Establish the Artifact

- Confirm learner level, subject, objectives, language, format, length, and assessment needs.
- Classify the result as an ordinary assignment, worksheet, quiz, or formal exam.
- Preserve supplied requirements and facts. Separate prompts, solutions, hints, rubrics, and
  instructor notes clearly.

## 2. Select a Template When Useful

When the target is not governed by an existing scaffold, search the Tylina Template Registry with
focused terms such as `exam` and `worksheet` before hand-writing a page shell. This applies to a
blank draft and to an explicitly distinct new artifact in a populated workspace; materialize the
latter at a conflict-free path. For a Chinese exam, include Chinese-oriented candidates such as
`ezexam` and `examora` when the catalog returns them.

Inspect each shortlisted exact spec and API. Rank candidates by language, artifact fit, current API,
license, compiler compatibility, preview, and required features. Current stars or repository
activity may break a close tie when fresh metadata is available, but are not compatibility proof.
When needed and browsing is available, query
`https://orangex4.github.io/typst-universe-with-stars/packages.json`, check `updated_at`, and match
the exact package identity. Never bake counts or rankings into the Skill.

Apply the selected candidate through the template workflow in
`typst-authoring/references/templates-and-packages.md`. If none fits, use a semantic native Typst
structure rather than forcing a package.

## 3. Verify

Validate the current main, then inspect representative pages and every answer/rubric boundary.
Check pagination, writable space, numbering, scoring totals, answer visibility, and language level.
