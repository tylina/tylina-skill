# Custom Plain Themes

Plain themes are lightweight color/typography schemes. They compile fast, have minimal complexity, and are ideal for quick presentations or as starting points for customization.

| Theme | Style | Best For |
|-------|-------|----------|
| **Aurora** | Northern Lights inspired, dark background with vibrant  | Tech talks, creative showcases, conference presentations |
| **Cherry** | Japanese cherry blossom (sakura) inspired — soft pinks, | Cultural presentations, art, literature, aesthetic topics |
| **Coral** | Warm, vibrant, modern — coral/salmon tones with teal ac | Marketing, creative pitches, startup presentations |
| **Emerald** | Luxurious, premium — emerald green with gold accents | Finance, luxury brands, premium corporate events |
| **Lavender** | Soft, elegant, calming purple/lilac tones | Wellness, education, psychology, design topics |
| **Midnight** | Dark, elegant, midnight sky-inspired | Tech conferences, developer talks, dark mode lovers |
| **Monochrome** | Swiss/International design, black-and-white minimalism | Formal business, design portfolios, architecture |
| **Nordic** | Scandinavian-inspired — muted cool tones, clean lines,  | Academic talks, clean design, functional presentations |
| **Rosewood** | Warm, earthy, sophisticated — inspired by rosewood furn | Architecture, interior design, history, premium brands |
| **Slate** | Dark professional with amber accents | Tech product launches, keynotes, sophisticated presentations |
| **Sunset** | Warm, gradient-rich, sunset-inspired | Motivational talks, creative showcases, storytelling |
| **Terracotta** | Mediterranean warm earth tones | Travel, culture, food, architecture, interior design |


> Each theme directory contains `theme.md`, `demo.typ`, and `template.typ`.

> **Content enhancement**: Plain themes pair well with mitex (math), lovelace (pseudocode), cheq (checklists), and merman (Mermaid flowcharts/Gantt) for academic content. Data-heavy talks benefit from lilaq charts, or gribouille when layered statistical mappings are the better model. Code blocks work directly (template handles styling); use codly only for zebra-stripe aesthetic. See `templates/packages/README.md`.
