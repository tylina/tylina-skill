# Builtin Themes (Touying 0.7.4)

These themes ship with the Touying package — no local files needed. Import directly with `#import themes.<name>: *`.

> **Note**: Prefer custom themes for visual richness. Builtin themes are best when the user explicitly requests one or when maximum simplicity is needed.

| Theme | Style | Best For | Import |
|-------|-------|----------|--------|
| **Aqua** | Beautiful, decorative backgrounds | General presentations, visually appealing talks | `#import themes.aqua: *` |
| **Dewdrop** | Elegant, structured with navigation | Academic lectures, multi-section talks, course mat | `#import themes.dewdrop: *` |
| **Metropolis** | Modern, elegant (Beamer Metropolis-inspired) | Academic talks, conferences, technical presentatio | `#import themes.metropolis: *` |
| **Simple** | Minimal, clean | Quick presentations, prototyping, simple talks | `#import themes.simple: *` |
| **Stargazer** | Versatile, polished, everyday use | Everyday use, versatile presentations, research ta | `#import themes.stargazer: *` |
| **University** | Professional, branded, institutional | University lectures, institutional presentations,  | `#import themes.university: *` |
