## Description

Silky Slides INSA is an official-style presentation theme for the INSA (Institut National des Sciences Appliquees) group of French engineering schools. It implements the INSA graphic charter with branded SVG backgrounds for title slides, section slides, and footer elements. Each slide type uses pre-designed backgrounds from the INSA visual identity, with the school's logo automatically inserted based on the `insa` parameter.

The theme supports three INSA schools (Rennes, Hauts-de-France, Centre Val de Loire) and features two title slide layout variants: a simple layout (title + subtitle only) and a visual layout (title + subtitle + custom visual content on the right). Section slides support optional descriptions, and the theme uses the INSA-specified typography with League Spartan for headings and Source Serif for body text.

**Recommended fonts**:
- **League Spartan** (headings) -- install the static "Bold" version
- **Source Serif** (body text) -- install static Regular, Bold, and Italic variants

**Font fallback chains**:
- Headings: League Spartan -> Arial -> Liberation Sans
- Body: Source Serif -> Source Serif 4 -> Georgia -> (Typst default)

Download fonts from: https://github.com/SkytAsul/INSA-Typst-Template/tree/main/fonts

**Note**: Typst may not recognize variable font versions. Install static font files instead. See [typst/typst#185](https://github.com/typst/typst/issues/185).

## Quick Start

```typst
#import "@preview/silky-slides-insa:0.2.0": *

#show: insa-slides.with(
  title: "Presentation Title",
  subtitle: "Author Name -- Course Title",
  insa: "rennes",
)

= First Section

== First Slide

Your content here.

== Second Slide

- Bullet points work naturally
- Use #text(fill: insa-colors.primary)[INSA red] for brand colors
```

## Theme Parameters (`insa-slides`)

The `insa-slides` entry function accepts these direct parameters (NOT inside `config-info`):

| Parameter | Type | Default | Description |
|---|---|---|---|
| `title` | content | `"Titre a definir"` | Presentation title, displayed on the title slide |
| `subtitle` | content | `"Sous-titre a definir"` | Presentation subtitle |
| `title-visual` | content/none | `none` | Visual content for the right side of the title slide. When set, switches to the "visual" layout variant |
| `insa` | string | `"rennes"` | INSA school identifier. Determines which logo and branding assets to use |

### Supported INSA Schools

| School | `insa` value | Logo used |
|---|---|---|
| INSA Rennes | `"rennes"` | `assets/rennes/logo-white.png` |
| INSA Hauts-de-France | `"hdf"` | `assets/hdf/logo-white.png` |
| INSA Centre Val de Loire | `"cvl"` | `assets/cvl/logo-white.png` |

Using an unsupported `insa` value will trigger an assertion error.

### Important: Parameter Style

Unlike most Touying themes, `insa-slides` takes `title`, `subtitle`, `title-visual`, and `insa` as **direct named parameters** -- NOT inside `config-info()`:

```typst
// CORRECT -- direct parameters
#show: insa-slides.with(
  title: "My Presentation",
  subtitle: "My Subtitle",
  insa: "rennes",
)

// ALSO WORKS -- you can pass additional Touying config if needed
#show: insa-slides.with(
  title: "My Presentation",
  subtitle: "My Subtitle",
  insa: "hdf",
  config-page(paper: "presentation-16-9"),  // already the default
)
```

## Available Slide Types

### Title Slide -- `#title-slide()`

Creates the branded opening slide with the INSA graphic charter background. The title slide is automatically generated by `insa-slides`, but can be created again explicitly with overridden parameters.

Two layout variants exist:
- **Simple layout**: When `title-visual` is `none` (default). Uses `slide-title.svg` background. Shows logo, title (white, 40pt, bold), and subtitle (black, 20pt).
- **Visual layout**: When `title-visual` is set to content. Uses `slide-title-visual.svg` background. The visual content is placed in a 12cm x 11cm area on the right side of the slide.

```typst
// Simple layout (default)
#title-slide()

// Visual layout with an image
#title-slide(
  title: "A Different Title",
  subtitle: "Overridden Subtitle",
  title-visual: image("my-image.png"),
)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `title` | content | from `config-info` | Override the presentation title |
| `subtitle` | content | from `config-info` | Override the subtitle |
| `title-visual` | content/none | from `config-info` | Override the visual content |

**Layout details**:
- Logo: positioned at (2.02cm, 1.89cm), width 4.94cm
- Title: positioned at (2.02cm, 4cm), up to 16cm wide (11.8cm in visual layout), white text, 40pt, bold, League Spartan
- Subtitle: positioned at (2.02cm, 12.8cm), black text, 20pt, League Spartan
- Visual (when present): positioned at (13.95cm, 1.9cm), 12cm x 11cm area, centered content

### Content Slide -- `== Heading`

Standard content slides are created with level-2 headings. The upstream rule inserts a page break, renders the heading at 30pt, and leaves 0.5em below it. This is a package-owned exception to the minimum ordinary-stack rhythm: changing it locally duplicates page breaks. Keep it read-only and use the package's normal content-slide layout.

```typst
== Slide Title

Content goes here with *bold*, _emphasis_, and regular text.

- Bullet point (marker: filled circle)
  - Sub-point (marker: plus sign)
```

Content slides have:
- A small INSA footer image (3.5cm) in the bottom-right corner (`assets/footer.png`)
- A slide counter in a 1.75cm x 1.75cm box at the bottom-right, white text over the footer
- Default margins: x = 2.02cm, y = 1.71cm

**Note**: The theme sets `slide-level: 2` in `config-common`, meaning level-1 headings (`=`) trigger section slides, and level-2 headings (`==`) create content slides within those sections.

Use level-2 headings for content slides. Version 0.2.0 owns Touying 0.7.4 and supports Touying speaker notes and overlay primitives; still inspect every physical page after using `#pause`, `#only`, or `repeat`.

### Section Slide -- `= Heading` or `#section-slide(...)`

Section slides use the `slide-section.svg` branded background. They display the section title in large bold text (40pt, black) and an optional description (24pt, black).

There are two ways to create section slides:

```typst
// Method 1: Automatic via level-1 heading (no description)
= My Section Title

// Method 2: Explicit function with description
#section-slide(
  [Section Title],
  description: [This section covers the main results of our analysis.],
)
```

| Parameter | Type | Description |
|---|---|---|
| `title` (positional) | content | The section title (displayed at 40pt bold) |
| `description` | content | Description text below the title (displayed at 24pt) |
| `add-heading` | bool | Whether a manual section slide adds its title to the outline |

**Layout details**:
- Title: positioned at (2.02cm, 4.1cm), 20cm wide, 6.8cm tall area, bottom-aligned, 40pt bold black
- Description: positioned at (2.02cm, 11.5cm), 17cm wide, 4cm tall area, top-aligned, 24pt black
- Slide counter: bottom-right, same as content slides

## Content Features

### INSA Brand Colors

The theme exposes INSA brand colors through the `insa-colors` dictionary, which can be used anywhere in your presentation:

```typst
// The primary red is dark enough for direct emphasis on white.
#text(fill: insa-colors.primary)[Red INSA text]

// Use the lighter secondary and tertiary colors as fills with dark text.
#box(fill: insa-colors.secondary, radius: 4pt, inset: 8pt)[
  #text(fill: black)[Gold/orange accent]
]
#box(fill: insa-colors.tertiary, radius: 4pt, inset: 8pt)[
  #text(fill: black)[Light pink accent]
]

// Primary-color callout
#rect(fill: insa-colors.primary, radius: 4pt, inset: 8pt)[
  #text(fill: white)[Highlighted content]
]
```

### Incremental Reveal (`#pause`)

The package re-exports Touying's animation primitives. Enable `#pause` only when progressive disclosure serves the content, then compile and check every physical page:

```typst
== Step 1

First this content appears.

== Step 2

Then this content appears.
```

### List Markers

The theme customizes list markers:
- Level 1: `sym.circle.filled.tiny` (small filled circle)
- Level 2: `sym.plus` (plus sign)

### Typography Settings

The theme initializes with these text settings:
- Body text: Source Serif font family, 22pt
- Headings: League Spartan font family
- Level-2 headings: 30pt with page break and 0.5em below; a package-owned page-break exception that must not be locally overridden

## Color Scheme

The theme maps to Touying's `config-colors` using the INSA brand palette:

| Color Name | Hex Value | RGB | Usage |
|---|---|---|---|
| `primary` | `#e42618` | `rgb(228, 38, 24)` | INSA red -- primary brand color, used for emphasis and accents |
| `secondary` | `#f69f1d` | `rgb(246, 159, 29)` | INSA gold/orange -- secondary brand color |
| `tertiary` | `#f5adaa` | `rgb(245, 173, 170)` | INSA light pink -- tertiary/soft accent |

Access these colors via `insa-colors.primary`, `insa-colors.secondary`, and `insa-colors.tertiary`.

### Background Assets

The theme uses pre-designed SVG/PNG backgrounds from the INSA graphic charter:
- `slide-title.svg` -- Simple title slide background
- `slide-title-visual.svg` -- Visual title slide background (wider right area)
- `slide-section.svg` -- Section divider slide background
- `footer.png` -- Small branded footer element (bottom-right of content slides)
- `{insa}/logo-white.png` -- White school logo (per-school, on title slide)

## Page Configuration

```typst
config-page(
  paper: "presentation-16-9",
  margin: (x: 2.02cm, y: 1.71cm),
)
```

Title and section slides override margins to `(left: 0pt, top: 0pt)` and use full-bleed SVG backgrounds.

## Internal Architecture

The theme defines these internal functions:

- `_footer(self, color: black)` -- Renders the page footer with slide counter; the counter is placed in a 1.75cm x 1.75cm box at bottom-right
- `title-slide(..args)` -- Public title slide function with simple/visual layout switching
- `section-slide(title, description: none, add-heading: true)` -- Public section-slide function; automatic section slides call it with `add-heading: false`
- `slide(..args)` -- Content slide function with footer background
- `insa-slides(...)` -- Main entry function / show rule

### Config Common Settings

```typst
config-common(
  slide-level: 2,
  new-section-slide-fn: section-slide.with(add-heading: false),
  slide-fn: slide,
)
```

This means:
- Level-1 headings (`=`) create section dividers
- Level-2 headings (`==`) create content slides
- The slide function used for content is the theme's custom `slide` with INSA footer
