# Custom Canvas Themes

Canvas themes are the highest visual tier — featuring hand-crafted SVG compositions, layered `place()` layouts, and dramatic visual storytelling. Each slide can be a unique editorial spread.

> **When to use these**: Choose Canvas when bespoke SVG/spatial composition materially helps and the executor can safely handle Typst content/code modes, the selected theme API, and a compile probe. Otherwise use the theme in Rich mode by calling pre-built components without custom `place()` layouts.

> **Aesthetic diversity**: These themes span a wide range of visual worlds — from brutalist concrete to delicate botanical specimens, from neon vaporwave to classical porcelain. Choose based on the *feeling* you want to evoke, not a rigid topic match.
