# Mahogany Theme for Touying 0.7.4

## I. Project Information

| Item | Value |
| ---- | ----- |
| **Theme Name** | mahogany |
| **Best For** | Executive boardroom presentations, leadership talks, financial reports, strategy decks |
| **Style Objective** | Authoritative / Executive Warmth |
| **Complexity Level** | Rich |

Rich wood-tone warmth with burgundy, cream, and dark wood brown. Evokes leather-bound books and polished furniture. Authoritative yet warm, with brass-like divider lines and SVG wood grain texture accents on light cream backgrounds.

## Design Philosophy

- **Executive Authority**: Deep mahogany and burgundy convey gravitas and leadership
- **Warm Craftsmanship**: Wood grain textures and brass ornaments feel handcrafted and premium
- **Bookplate Heritage**: Ornamental frames and corner flourishes reference fine bookbinding
- **Brass Elegance**: Diamond centerpiece dividers and scrollwork add subtle luxury

## Typography

- Body: 20pt, dark warm text
- Headings: Bold mahogany with brass accent line

## SVG Decorations

- **Wood grain**: Horizontal wavy lines simulating polished mahogany grain (full-page)
- **Brass divider**: Elegant horizontal rule with diamond centerpiece and scrollwork
- **Corner bracket**: Decorative corner flourish with rounded curves and dots
- **Bookplate frame**: Full-page ornamental border with tick marks
- **Brass flourish**: Small inline wave ornament with endpoint dots

## Slide Types

- `title-slide` -- Bookplate frame, mahogany sidebar, wood grain texture, brass flourish
- `slide` -- Warm cream bg, wood grain atmosphere, mahogany header, brass accent
- `new-section-slide` -- All four corner brackets, brass flourish and divider, centered title
- `focus-slide` -- Burgundy background, brass frame rectangle, cream text
- `ending-slide` -- Bookplate frame matching title slide, "closing the book" bookend

## Components

- `concept-card(title, body, accent)` -- Mahogany-bordered card with warm tan header bar
- `insight-box(title, body)` -- Left-bordered highlight with burgundy accent
- `stat-card(label, value, note)` -- Large brass-colored number with dot decoration
- `executive-card(title, body)` -- Premium card with top brass rule
- `panel-box(title, body)` -- Full-width panel with brass divider separator
- `quote-card(quote, author)` -- Leather-bound quote with SVG brass flourish
- `kpi-card(label, value, trend, trend-color)` -- Brass-accented metric with optional trend
- `callout-box(title, body, accent)` -- Warm tan background with diamond bullet
- `mahogany-tag(content, color)` -- Small inline pill/capsule label
