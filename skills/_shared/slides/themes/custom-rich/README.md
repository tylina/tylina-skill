# Custom Rich Themes

Rich themes provide structured component libraries (cards, metrics, tables) that handle visual complexity for you. Ideal when you want polished results without writing SVG or complex `place()` layouts.

> **Selection tip**: Match the *visual atmosphere* to your content mood, not just the topic category. A warm amber theme can work for finance; a dark navy theme can suit art history.

> **Content enhancement**: After selecting a theme, enhance slides with packages — mitex (math formulas), lilaq (standard charts), gribouille (layered Grammar-of-Graphics plots), merman (Mermaid flowcharts/Gantt), codly (code with zebra stripes), lovelace (pseudocode), and cheq (checklists). Code blocks work directly (template handles styling). See `templates/packages/README.md`.
