# Pressed Linen Theme for Touying 0.7.4

## I. Project Information

| Item | Value |
| ---- | ----- |
| **Theme Name** | pressed-linen |
| **Best For** | Wellness, design studios, botanical, lifestyle, creative presentations |
| **Style Objective** | Organic / Sophisticated Calm |
| **Complexity Level** | Rich |

A textured linen/paper aesthetic with pressed botanical leaf silhouettes. Subtle cream background with sage green and dusty rose accents. Inspired by Japanese washi paper and dried flower pressing -- light, airy, and sophisticated.

## Design Philosophy

- **Botanical Authenticity**: Eucalyptus branches and fern fronds rendered as realistic pressed-leaf silhouettes
- **Linen Texture**: Subtle crosshatch grain pattern evokes handmade paper throughout
- **Organic Softness**: Rounded card corners, gentle borders, and muted earthy tones
- **Pressed Flower Heritage**: Dried flower motifs reference the Victorian herbarium tradition

## Typography

- Body: 20pt, warm body text color
- Headings: Semibold, dark text with sage green accent line

## SVG Decorations

- **Eucalyptus branch**: Full botanical stem with alternating oval leaves
- **Fern frond**: Delicate pressed fern with paired leaflets
- **Linen texture**: Subtle crosshatch horizontal/vertical grain pattern (full-page)
- **Pressed flower**: Simple dried flower with six petals and center dot
- **Botanical frame**: Delicate vine/leaf border with corner motifs
- **Botanical divider**: Gentle wavy line separator with scattered dots
