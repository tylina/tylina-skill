# Laurel Crown — Visual Design Specification

## Theme Identity
**Metaphor**: Academic laurel wreath ceremony
**Tier**: Rich
**Best for**: Thesis defense, research proposals, doctoral presentations

## Color Palette
| Role | Color | Hex |
|------|-------|-----|
| Background | Warm Ivory | #FEFDF5 |
| Text Dark | Deep Burgundy | #5B1A2A |
| Accent | Scholarly Green | #2E5944 |
| Highlight | Gold | #B8860B |
| Muted | Warm Gray | #8B7D6B |

## Typography
- Base: 18pt; the consuming deck selects its serif/CJK font pair
- Headings: Bold, burgundy
- Labels: Green accent

## Decorative Elements
- Laurel wreath SVG (title/ending bookend): 12+ leaf shapes, varying opacities
- Vine divider SVG: horizontal vine separator with leaves
- Full-page folio texture: faint vine fragments provide persistent atmosphere on content slides

## Component Inventory
1. `chapter-block` — full-width dark header bar
2. `laurel-card` — dashed gold border + leaf SVG corners
3. `contribution-item` — gold bullet + text, no border
4. `vine-divider` — SVG leaf-vine separator
5. `honors-tag` — pill badge with leaf icon
6. `finding-quote` — vine-border blockquote
7. `milestone-stat` — large number + gold underline

## Slide Types
- Title: Full laurel wreath frame + gold trim
- Section: Green accent + vine decoration
- Content: Subtle leaf corner marks (atmosphere)
- Focus: Burgundy statement page with ivory type and gold vine accents
- Ending: Wreath frame (bookend with title)
