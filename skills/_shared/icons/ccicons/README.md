# CC Icons — Creative Commons

**Package**: `@preview/ccicons:1.0.1`
**Icon count**: 20+

## Description

Creative Commons license icons for Typst documents. Adapted from the LaTeX ccicons package.

## Usage

```typst
#import "@preview/ccicons:1.0.1": *

#cc-by          // CC BY
#cc-by-sa       // CC BY-SA
#cc-by-nc-nd    // CC BY-NC-ND
```
