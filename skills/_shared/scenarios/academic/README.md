# Academic Paper Scenarios

These Tylina-owned templates are offline, package-free starting workspaces. They provide structure
and visible replacement prompts, not claims, evidence, citations, venue compliance, or permission
to replace an existing paper.

| Entry | Best for | Files |
|---|---|---|
| `research-paper` | A short empirical or methods paper with an abstract, stable labels, references, and an appendix | `main.typ`, `paper.typ`, `references.bib`, `README.md` |

Materialize the exact template with `template.create`; then replace every marked prompt with the
user's supplied contribution, evidence, authorship, and bibliography. Compile before expanding the
scaffold, and inspect the title block, equations, references, tables, and page transitions.
