# Research Paper

This is a package-free paper scaffold for real compilation before a venue template is selected.
It deliberately contains prompts instead of invented findings. `paper.typ` owns reusable layout;
`main.typ` owns document facts and content; `references.bib` demonstrates a real bibliography file.

After materialization:

1. Replace every bracketed prompt and the example title/author metadata.
2. Add only supplied or verified claims, measurements, figures, and bibliography records.
3. Preserve semantic labels when moving content.
4. Compile `main.typ` and visually inspect every affected page.

Use a venue's exact template instead when the user has supplied or selected one.
