# Homework

`assignment.typ` owns the question and solution presentation. `main.typ` owns the canonical task
content. The default output hides instructor solutions; compile with `--input solutions=true` for
the instructor edition. Replace all prompts, answers, dates, and points with supplied material.

Validate both editions and confirm that the learner output contains no answer-only page, style,
metadata, or filename claim. Anyone with the source can still read its solution content.
