# Printable Exam

`assessment.typ` owns print layout and edition switching. `main.typ` is the canonical question
source. The default learner edition has candidate fields and writable space; compile with
`--input solutions=true` for the answer edition.

Before delivery, confirm learner, locale, duration, aids, paper size, duplex behavior, point total,
question coverage, answer visibility, writable space, and print scale. This scaffold does not
encode an official curriculum or secure answers from readers of the source.
