# Table Templates

These package-free workspaces keep data, semantic table structure, and reusable presentation
separate. Materialize the complete leaf directory so its entrypoint and style module stay
together.

| Entry | Best for | Contract |
|---|---|---|
| `data-table` | Comparisons, measurements, inventories, and evidence tables | Preserve every value, unit, label, missing-value meaning, order, source, and note |

Do not turn a visual grid into a table when cells are unrelated. Replace every sample value and
compile with the longest real labels before delivery.
