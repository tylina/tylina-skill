# Long-form Scenarios

These offline, package-free workspaces provide a stable multi-file baseline before an exact
template is selected. They separate reusable layout from authored sections and keep one explicit
`main.typ` entrypoint.

| Entry | Best for | Structure |
|---|---|---|
| `report` | Decision, technical, field, or project reports | Front matter, summary, numbered sections, findings, recommendations, appendix |
| `course-notes` | A growing set of class, reading, or workshop notes | Title page, outline, chapter include, definitions, examples, review prompts |

Replace every prompt with supplied material. Do not fabricate findings, decisions, legal text,
identifiers, sources, or edition history.
